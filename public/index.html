                What is not in it

                  Welcome to MoleBridge

                  What this is

                  A stoichiometry problem, worked one step at a time. You enter every value along the way — the balanced coefficients, the molar mass, the moles, the ratio — and you cannot move on until the step in front of you is right.

                  When a step is wrong, MoleBridge works out which mistake produces that exact number and tells you, instead of just marking it wrong. If the mistake is an algebra one, it shows you three lines of the algebra using your own numbers.

                  What this is not

                  • It is not a solver. It will not do a problem for you, and it never shows you an answer before you have tried it.
                  • It is not a grade. The code at the end records how far you got and where you got stuck. Whoever set it decides what that is worth.
                  • It does not know who you are. It asks for the roster number you were given and nothing else — no name, no email, no account.

                  How a session goes

                  1. Type in the roster number and assignment key you were given.
                  2. Work each problem stage by stage. Getting one wrong costs you nothing except that the problem stops counting as first-try.
                  3. At the end you get a short code. Type it in wherever you hand your work in.

                  Nothing is sent, and what is kept stays here

                  MoleBridge has no account and no server. Nothing you type ever leaves the device. What it keeps, it keeps on this device only: the problem you are in the middle of, so closing the tab does not cost you your work; your place in the lessons; and how you have set it up to read. None of that is sent anywhere and none of it is in the code you hand in.

                    Things worth knowing

                    • There is no time limit. The code records how long you had the app open, and that is not a score. Time you spend away from it is not counted at all.
                    • Getting a step wrong costs you nothing. Try it as many times as you like. What the code carries is how many were right first time, not how many tries you took.
                    • You can stop and come back. Close the tab, shut the lid, walk away. The app remembers where you were and what you had typed.
                    • Nothing you type is stored anywhere but this device, and none of it is in the code you hand in.
